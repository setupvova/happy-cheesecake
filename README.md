# happy-cheesecake или счастливый чизкейк 

Калькулятор калорий с подсчётом БЖУ. Активностей. Отдыха. Состояния.Помогает снижать индекс массы тела, либо набирать массу тела (мышцы в основном). Так же отслеживает сон, отдых, активности, психоэмоциональное состояние. 
## зачем
Считал каллории, прогресс, часы сна - в голове.
Решил, что хочу чтобы это стало наглядно - в моём телефоне.
## что умеет 
- считает калории
- показывает БЖУ
- показывает сколько спал и сколько необходимо - даёт рекомендации
- показывает какие активности добавить - так же рекомендует
- отслеживает психоэмоциональное состояние - развивате осознанность
## как работает
  1. введите название продукта
  2. укажите граммы
  3. нажмите "добавить"
  4. смотрите итог внизу
## другое и остальное
  1. заполнение данных об активности - кратко одним словом 
  2. заполнение данных о сне - во сколько встал, во сколько лёг, сколько часов проспал
  3. отследил и заполнил в каком настроение - кратко пару фраз
